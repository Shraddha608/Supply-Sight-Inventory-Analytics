# Supply Sight — Inventory & Demand Intelligence

## 📊 Project Overview

Supply Sight is an end-to-end inventory analytics project built using
Microsoft Excel and Power BI to analyze inventory levels, demand forecasts,
procurement activity, and stock risk.

The project demonstrates the complete workflow from data cleaning and
preparation in Excel to data modeling, DAX calculations, and interactive
dashboard development in Power BI.

## 🧹 Excel Data Preparation

The datasets were cleaned and prepared in Excel before being imported into
Power BI.

Key activities included:

- Data quality checks
- Missing/invalid value checks
- Data type validation
- ID validation
- Duplicate/error checks
- Date and month-year preparation
- Preparing datasets for Power BI modeling

## 📈 Power BI Analysis

The dashboard provides insights into:

- Current Stock
- Forecast Demand
- Stock Risk
- Stock Gap
- Total Purchase Value
- Total Received
- Inventory trends over time
- Top products by stock
- Products at risk

## 🧮 DAX & Data Modeling

Created DAX measures for inventory and demand analysis and developed
relationships between calendar, product, supplier, purchase order,
inventory transaction, and demand forecast data.

Time-based analysis was implemented to compare inventory levels against
forecast demand.

## 🎯 Key Business Questions

The dashboard helps answer:

1. How much inventory is currently available?
2. How does forecast demand compare with inventory?
3. Which products are at risk of stock shortages?
4. Which products have the highest inventory levels?
5. How much has been spent on procurement?
6. How much inventory has been received?
